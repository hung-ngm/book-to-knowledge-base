# book-to-knowledge-base

An Agent Skill that turns books into one shared Library: linked markdown notes that humans browse in a viewer like Obsidian and agents search with grep.

- Plan and requirements: [docs/plans/v1-build-plan.md](docs/plans/v1-build-plan.md)
- Vocabulary: [GLOSSARY.md](GLOSSARY.md)
- Decisions: [docs/adr/](docs/adr/)

The text extractor (`book_to_kb/`) is vendored from [book-to-skill](https://github.com/virgiliojr94/book-to-skill) (MIT). See [ADR 0002](docs/adr/0002-vendor-the-extractor.md).
